# Source Tier Model 评估报告 (2026-05-15)

## 评估配置
- 测试集: 125 samples (A:40, B:54, C:15, D:16)
- 模型: qwen2.5:7b (few-shot, 无 LoRA 训练)
- 架构: 三层约束 (硬规则 → Pydantic 校验 → 置信度门控)
- 平均延迟: 1.58s/sample

## 结果对比

| Tier | 规则基线 | qwen2.5:7b few-shot | Delta |
|------|---------|---------------------|-------|
| A    | 100%    | 80.0%               | -20pp |
| B    | 100%    | 77.8%               | -22pp |
| C    | 6.7%    | 46.7%               | +40pp |
| D    | 93.8%   | 75.0%               | -19pp |
| 总体 | 88.0%   | 74.4%               | -14pp |

## 关键发现

1. 模型在 C 级(行业协会/研究机构)上远超规则 (+40pp)
2. 规则在 A/B 级上仍然更强 (硬规则 100% 覆盖已知域名)
3. 三层架构有效: 硬规则短路明确案例, 模型处理边界
4. Prompt 优化从 42.4% 提升到 74.4% (+32pp)
