# 信息源分级制度（A/B/C/D）—— 完整分类规则

## 概述

Source Tiering 将信息源分为 A/B/C/D 四个可信度等级。分级依据三个维度：
1. **域名**（domain）：信息源的发布机构
2. **URL 路径**（url_path）：页面类型（政策原文 / 新闻 / 公告 / 报告）
3. **标题**（title）：内容性质（法规通知 / 新闻报导 / 解读 / 商业分析）

---

## A 级：政策法规原文（最高可信度）

### 定义
政府官方发布的**政策法规原文**——具有法律效力的正式文件，可直接作为一手证据引用。

### 触发规则（按优先级）

| # | 规则 | 示例 | 权威分 |
|---|------|------|--------|
| 1 | 中央部委域名 | `www.gov.cn`, `ndrc.gov.cn`, `miit.gov.cn`, `mee.gov.cn` 等 11 个部委 | 0.98 |
| 2 | .gov.cn + PDF 附件 | `xxx.gov.cn/.../附件.pdf` | 0.95 |
| 3 | .gov.cn + 政策路径标记 | URL 含 `/zcfb/`, `/xxgk/`, `/flfg/`, `/zwgk/wjk/`, `/gkmlpt/` | 0.93 |
| 4 | .gov.cn + 政策内容标记 | URL/标题含 `办法`, `措施`, `行动计划`, `实施细则`, `通知`, `意见`, `方案` | 0.90 |

```
  └─ 其他 → B
域名不是 .gov.cn？ → 基本不是 A
```

## C 级：半官方 / 专业机构（中等可信度）

### 定义
行业协会、研究院所、咨询机构、政策解读——可作背景参考和交叉验证，**不能作为一手证据**。

## 时效性修正规则

无论域名和路径如何，**年份会降级**：

| 年份范围 | 最高等级 | 示例 |
|----------|----------|------|
| 2025-2026 | 不降级 | 最新政策 |
| 2023-2024 | C（降一级） | 旧政策文件——仅历史参考 |
| 2020-2022 | C（降两级） | 过时政策——需找最新替代 |
| 2020 以前 | D | 严重过时——排除使用 |

**注意**：中央部委 + 政策原文即使年份较旧，作为"历史政策权威来源"仍可保持 A（具体由硬规则判断）。

## 数据集构建要点

### 1. 每个样本必须包含的字段
```json
{
  "domain": "www.hubei.gov.cn",
  "url": "https://www.hubei.gov.cn/zwgk/xwdt/202401/t20240110_001.html",
  "title": "湖北省政府召开新能源产业发展座谈会",
  "tier": "B",
  "authority_score": 0.75,
  "usage_note": "政府新闻动态——需找配套政策文件核实",
  "confidence": 0.95
}
```

### 2. CoT 推理链格式（推荐）
训练数据中应包含推理过程，利用 R1 蒸馏模型的推理能力：

```
### 推理过程
Step 1 - 域名: www.hubei.gov.cn → .gov.cn 结尾，政府网站
Step 2 - 路径: /zwgk/xwdt/ → 路径含 /xwdt/，这是新闻动态路径，不是政策发布路径
Step 3 - 标题: "召开...座谈会" → 会议新闻，非政策法规
结论: 虽然是.gov.cn，但内容是新闻动态而非政策原文 → B 级

### 输出
{"tier": "B", "authority_score": 0.75, "usage_note": "政府新闻动态——需找配套政策文件核实", "confidence": 0.95}
```

### 3. 必须包含的"硬负例"
数据集必须包含这类对比样本，教模型区分 A vs B vs C：

| 模式 | 正例（A） | 反例（B 或 C） |
|------|----------|---------------|
| `.gov.cn + /xwdt/` | — | B: 政府新闻动态 |
| `.gov.cn + /zcfb/` | A: 政策原文 | — |
| `.gov.cn + /jdhy/` | — | C: 政策解读（非原文） |
| `.gov.cn + 旧年份` | — | C: 旧政策文件 |
| `中央部委 + /xinwen/` | — | B: 部委新闻（非政策） |
| `.org + 权威标题` | — | C: 行业协会（非政府） |
| `.com + 专业报告` | — | C或D: 商业机构报告 |

### 4. 数据平衡目标
| Tier | 最低样本数 | 理想比例 |
|------|-----------|---------|
| A | 300 | 25% |
| B | 350 | 30% |
| C | 300 | 25% |
| D | 250 | 20% |
| **总计** | **1200+** | **100%** |

### 5. 数据来源建议
1. **真实数据**：从 Deep Research 报告中提取 source_assessments（已有 446 条）
2. **合成数据**：使用本规则文档中的域名/路径/关键词表自动生成
3. **人工标注**：重点标注 A/B 边界和 C/D 边界案例
4. **规则反标注**：用 `_classify_source()` 规则标注 → 人工审核修正
